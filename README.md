# VegCom

## Overview
VegCom is a cutting-edge web application designed to help users discover, share, and explore vegetarian and vegan recipes. Whether you're a seasoned plant-based eater or just looking to incorporate more plant-based meals into your diet, VegCom has something for everyone.

## Features
- **Recipe Discovery**: Browse through a vast collection of vegetarian and vegan recipes tailored to different dietary preferences and restrictions.
- **User Submissions**: Users can submit their own recipes, complete with cooking instructions and photos.
- **Recipe Sharing**: Share favorite recipes with friends and family through social media platforms.
- **Search Functionality**: Easily search for recipes based on ingredients, cuisine, or dietary restrictions.
- **Comment and Review System**: Leave feedback on recipes and read reviews from other users.

## Tech Stack
- **Frontend**: React.js for building a dynamic and responsive user interface.
- **Backend**: Node.js with Express.js for handling server-side logic and API requests.
- **Database**: MongoDB for storing user data and recipes.
- **Authentication**: JSON Web Tokens (JWT) for secure authentication and authorization.
- **Deployment**: Docker for containerization and easy deployment to cloud services.

## Setup Instructions
1. **Clone the repository**:
   ```bash
   git clone https://github.com/maatheuus/vegcom.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd vegcom
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Set up environment variables**:
   Create a `.env` file in the root directory and set the required variables (refer to the `.env.example` file).
5. **Run the application**:
   ```bash
   npm start
   ```
6. **Open your browser** and navigate to `http://localhost:3000` to see the application in action.
